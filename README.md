# Compound Interest Calculator

A web-based compound interest calculator application built with Java Servlets and JSP. This tool helps users calculate compound interest for their investments or loans.

## Features
- Web-based interface for easy access
- Compound interest calculations
- User-friendly form input

## Technology Stack
- Java 21
- Java Servlets
- JSP (JavaServer Pages)
- Maven for dependency management and building
- Web container (Tomcat) for deployment
